DAT_File_Processing A mask that separates the black regions from the lighter regions is created from the visible file using an Otsu thresholding algorithm implemented on a sliding 30x30 window. The visible and ultraviolet images are adjusted on a sliding 401x401 window by changing the center pixel of the sliding window so that the width and mean within the window is similar across the image. The visible and ultraviolet images each have three color separations, which are added together before being processed and combined in pseudocolor.
